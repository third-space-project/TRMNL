# Holo-Flights

A real-time holographic display that displays nearby flights using live flight data.

## Hardware
- ESP32 module (probably C3)
- TFT screen
- PCB
- Acrylic panes
- 3D printed frame
- SD Card holder
- SD Card
- GPS module
- Battery (optional)

## Firmware

- **On first startup:** A web portal opens / link it through app to add credientials to WIFI network
- **Look:** 
  **ESP32 fethces data => checks the planes => fethces image and caches it => display the planes with 10s buffer between each one.**

## SOFTWARE
## WEB APP - iOS - Android 

- A minimalistic app with selectable themes that fetches open source data for a range of 10-50 miles radius it shows callsign, model, carries and an image. Unique widget and 
  icons for Home Screen.
